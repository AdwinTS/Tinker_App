# 🚀 TinkHack 2025: The Flagship Hackathon Landing Page

This is the official landing page for **TinkHack 2025**, the flagship hackathon hosted by **TinkerHub MEC**.  
Built with **React** and styled using **Tailwind CSS**, this site is designed to be modern, interactive, and visually stunning — featuring **custom animations powered by Framer Motion** and a sleek high-tech aesthetic.

---

## ✨ Features

- **Futuristic Design**: Dark theme with Aurora background + cyan/purple gradient accents.  
- **Unique Navigation**: Interactive **Bubble Menu** for a dynamic, modern experience.  
- **Animated Timeline**: Vertical timeline with custom arrow connectors.  
- **Interactive Overview**: Accordion components for detailed, compact event info.  
- **Animated CTA**: Glowing **Register Now** button linked to external form.  
- **Responsive Layout**: Fully optimized for desktop and mobile devices.  

---

## 🖼️ Project Showcase

🔹 **Hero Section (Aurora Background & Title)**  
Full-screen landing zone featuring the animated "TinkHack 2025" title against a subtle Aurora effect.  

🔹 **Navigation (Bubble Menu)**  
Floating bubble navigation replaces the traditional navbar for a unique UI.  

🔹 **Event Overview (Accordion Boxes)**  
Expandable accordion sections for event details.  

🔹 **Timeline (With Arrows)**  
Vertical roadmap clearly detailing the hackathon schedule with animated connectors.  

🔹 **Sponsors & Contact**  
Stylish, animated sections to showcase partners and connect with the team.

## 🛠️ Technology Stack

| Technology       | Purpose                                                                 |
|------------------|-------------------------------------------------------------------------|
| **React**        | Core JavaScript library for building the UI                             |
| **Tailwind CSS** | Utility-first CSS framework for rapid styling                           |

## ⚙️ Getting Started

### Prerequisites
Make sure you have **Node.js** and **npm** (or yarn/pnpm) installed.

### Installation

Clone the repository:
```bash
git clone https://github.com/AdwinTS/Tinker_App.git
cd Tinker_App
```
